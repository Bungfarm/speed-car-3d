# 🏎️ SPEED CAR 3D (Radmin VPN Drift Multiplayer)

เกมแข่งรถ 3D ออนไลน์สไตล์ Need for Speed ผ่านวง LAN เสมือน (Radmin VPN) รองรับผู้เล่น 1–6 คน พร้อมระบบฟิสิกส์ดริฟต์ (E-Brake Drift), ไนตรัส ($N_2O$ Boost), เส้นทาง Racing Line นำทาง และธีมดาร์ค

## ✨ ฟีเจอร์หลัก
- **3D Graphics (Three.js):** กราฟิกสนามแข่ง 3D ยามค่ำคืน, ตึกระฟ้า, กำแพงเรืองแสง, และไฟนีออนใต้ท้องรถ (Underglow)
- **Multiplayer 1-6 คนผ่าน Radmin VPN:** เล่นผ่านเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่ม เพื่อนแค่เปิดลิงก์ IP Radmin ของโฮสต์
- **Drift & Nitro Physics:** ระบบฟิสิกส์การยึดเกาะยาง (Lateral Slip Grip), ดริฟต์เพื่อสะสมเกจไนตรัส และบูสต์พุ่งทะยาน
- **AI Bots:** มีบอท AI แข่งด้วยสำหรับซ้อมเล่นคนเดียวหรือเติมให้ครบ 6 คัน
- **Dark Theme UI:** เมนูคลีนดาร์ค มินิมอล มีแค่ "เริ่มเกม" กับ "ตั้งค่า"

## 🚀 วิธีการเปิดเล่น

1. ติดตั้ง Node.js ในเครื่องโฮสต์
2. เปิดโปรแกรม Radmin VPN แล้วเข้าห้องเดียวกันกับเพื่อน
3. ดับเบิลคลิกไฟล์ `START_SERVER.bat` (หรือรันคำสั่ง `node server.js`)
4. เข้าเล่นผ่านเบราว์เซอร์:
   - **สำหรับเครื่องโฮสต์:** `http://localhost:3000`
   - **สำหรับเพื่อนใน Radmin:** `http://<IP_RADMIN_ของโฮสต์>:3000` (เช่น `http://26.130.208.208:3000`)

## 🎮 ปุ่มควบคุม
- `W` `A` `S` `D` หรือ `ลูกศร` : เร่งเครื่อง / เลี้ยว / เบรก
- `Spacebar` + เลี้ยว : ดึงเบรกมือดริฟต์ (สะสมไนตรัส)
- `Shift` : ยิงไนตรัสบูสต์ความเร็ว
- `C` : เปลี่ยนมุมกล้อง 3D (Chase / Action / Hood)
- `G` : เปิด/ปิดเส้นไกด์นำทางบนถนน
- `R` : รีเซ็ตรถกลับมากลางถนน
